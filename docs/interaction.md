# 3. 全局交互协议

- **URL 参数协议**（/jobs 页）：`q`（关键词）、`region`（地区）、`city`（城市）、`org_type`（单位类型）、`job_type`（岗位类型）、`education`（学历）、`discipline`（主学科）、`secondary_discipline`（第二学科/技能）、`status`（招聘状态）、`sort`（newest/verified/deadline，缺省 newest）、`page`（页码，缺省 1）。筛选变化经 `router.replace` 同步到 URL（`src/app/jobs/page.tsx:39`），`scroll: false`；空值与缺省值不写入参数。
- **收藏存储协议**：localStorage 键 `jiaodian-favorites`，值为 JSON 数字数组；解析失败按空数组处理（`src/lib/use-favorites.ts:9`）。
- **错误呈现形态**：静态站点无网络失败场景；非法详情 ID 渲染 404 页（`notFound()`）；筛选无结果渲染空态文案（「没有找到匹配的岗位」）。
- **外链行为**：全部来源链接 `target="_blank" rel="noopener noreferrer"` 新标签页打开。
- **通用行为**：无登录、无表单提交到服务器、无防连点需求（收藏为幂等切换）。

# 4. 全局框架（Header / Footer）

- Header：左侧品牌「交点 Careers」链接回首页；右侧 6 个导航链接——探索岗位(/jobs)、方向分析(/analysis)、市场观察(/market)、实习岗位(/internships)、交叉方向(/directions)、收藏(/favorites)。移动端横向滚动。
- Footer：站点标语与来源声明，无交互。
- 非法输入：无输入控件；导航链接无失败态。

# 11. 维护者命令行交互规格

| 命令 | 输入 | 成功输出 | 失败表现 |
| --- | --- | --- | --- |
| `npm run audit:jobs` | 无参数 | `Audited {N} public jobs ({x} field-level, {y} source-level, {z} key-field) against source pages.` | 逐条错误行打印到 stderr，退出码 1 |
| `npm run audit:jobs:offline` | 无参数 | 同上，结尾 `(schema only)`；不发网络请求 | 同上（仅结构类错误） |
| `npm run collect:robotics` | 无参数 | `Generated {N} jobs from {M} public source URLs.` + 来源检查统计 + 输出路径 | 脚本异常退出码 1 |
| `npm run collect:robotics:offline` | 无参数 | 同上，跳过来源可访问性检查 | 同上 |
| `npm run build` | 无参数 | 构建成功，产物 `out/` | prebuild audit 失败时构建中止 |
| `update.sh [消息]` | 可选提交信息 | 提交并 `git push` | push 失败时脚本中止 |

错误分类（audit:jobs）：重复 ID、缺 verification_level、缺 source_title/source_evidence、待核实记录携带条件字段、逐字段核验非 HTTPS、含 demo 数据、来源 HTTP 非 200、来源标题/发布日期/证据片段未命中、fetch 异常——全部为行式错误输出，不区分错误码。

未决项：`update.sh` 直接 push 的行为与命令系统「推送统一经 ::push」的约定冲突，处置（废弃或改造）待用户决策。

# 12. 端到端交互序列

求职者路径：首页输入关键词+选地区 → 搜索 → /jobs 带参筛选 → 调整筛选/排序/翻页 → 点开 JobCard → 详情页核对核验层级与原页锚点 → 点击「前往来源页面」在原公告确认 → 返回收藏 → /favorites 复查。

维护者路径：向白名单数据文件追加记录 → `npm run audit:jobs` 在线核验通过 → 本地提交 → `::push` 推送 → Render 自动构建（prebuild offline 门禁）→ 站点更新。

# 13. 交互验收口径

1. /jobs 页 9 类筛选控件均生效且与 URL 参数一一对应；从带参 URL 打开能复现筛选状态。
2. 排序三选项行为：newest 按 published_at 降序、verified 按 last_verified 降序、deadline 按 deadline 升序（null 殿后）。
3. 详情页按核验层级渲染对应提示条；「待核实」记录无任何条件字段区块。
4. 收藏切换后刷新页面状态保持；详情页与列表页共享同一存储键。
5. 全部来源外链新标签页打开且带 rel="noopener noreferrer"。
6. `audit:jobs`（在线）通过时输出各层级计数；任一证据未命中时退出码为 1。
7. `collect:robotics` 生成三个输出文件且市场页统计与 JSON 内容一致。
8. 不存在的详情 ID 返回 404 页。
